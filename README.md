# برندبوک برگر ذغالی

سورس قابل‌ویرایش نسخهٔ ۰۲ برندبوک است: ۱۱ فصل و ۱۰۰ تصویر موکاپ مستقل. نسخهٔ عمومی فعلی در [لینک برندبوک](https://burger-zoghali-brandbook-2026.miimkhosravi52.chatgpt.site) دیده می‌شود.

## اجرا

به Node.js نیاز دارید. وابستگی خارجی لازم نیست.

```bash
npm run dev
```

آدرس پیش‌نمایش: `http://localhost:5173/`. تغییر فایل‌ها باعث بارگذاری دوبارهٔ صفحه می‌شود.

```bash
npm run check
npm run build
```

خروجی آمادهٔ میزبانی در `dist/` ساخته می‌شود. تغییرات GitHub به‌تنهایی لینک عمومی فعلی را به‌روزرسانی نمی‌کند؛ انتشار روی همان Site مرحلهٔ جداگانه‌ای است.

## ساختار

| مسیر | کاربرد |
| --- | --- |
| `index.html` | فصل‌بندی، متن‌ها و کارت‌های موکاپ |
| `styles.css` | چیدمان، رنگ، تایپ و پترن |
| `app.js` | وضعیت فهرست هنگام پیمایش |
| `assets/mockups/` | ۱۰۰ تصویر مستقلِ نمایش‌داده‌شده |
| `assets/atlases/` | ۱۵ تصویر مادرِ تولیدی برای بازبینی و برش دوباره |
| `assets/reference/` | مرجع لوگو و سردر ارسالی |
| `assets/fonts/` | قلم‌های متنی استفاده‌شده در صفحه |
| `data/mockups.json` | شماره، نام، فایل و منبع هر موکاپ |
| `AGENTS.md` | قواعد ثابت برای کار با Codex |

تصاویر موکاپ مفهومی‌اند. متن ریز داخل تصاویر، لوگوهای همکار و جزئیات ساخت برای تولید نهایی باید با فایل‌های رسمی و نمونه‌های واقعی کنترل شوند. مرجع لوگو در این پروژه JPEG است؛ فایل برداری دقیق هنوز لازم است.
